# HYPE Whale Tracker — приватные оповещения в Telegram

Никакого публичного канала — сообщения идут только тебе, лично, через твоего
собственного бота.

## Шаг 1 — создать личного Telegram-бота (2 минуты)

1. В Telegram открой **@BotFather**.
2. Отправь `/newbot`, дай боту любое имя (например `HypeWatchBot`).
3. BotFather пришлёт **токен** вида `123456:ABC-def...` — это `TELEGRAM_BOT_TOKEN`.
4. Напиши своему новому боту **любое сообщение** (например "привет") — это
   обязательно, иначе бот не сможет писать тебе первым.
5. Узнай свой `chat_id`: открой в браузере
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   и найди `"chat":{"id": ЧИСЛО, ...}` — это число и есть `TELEGRAM_CHAT_ID`.

Бот приватный по конструкции: только тот, у кого есть токен, может им
управлять, а сообщения уходят только в чат с твоим chat_id.

## Шаг 2 — вписать адреса кошельков

Открой `wallets.json` и замени пример на реальные адреса, найденные через
Arkham / HyperTracker:

```json
[
  { "label": "Grayscale HYPE", "address": "0x..." },
  { "label": "Кит №1", "address": "0x..." }
]
```

## Шаг 3 — настроить порог оповещений

В `config.json`:
- `threshold_usd` — минимальная сумма изменения в долларах, чтобы прислать
  алерт (по умолчанию 20000, можно сделать чувствительнее).
- `coins_of_interest` — список монет твоего вотчлиста, остальные игнорируются.

## Шаг 4 — запуск

### Вариант А: локально на своём компьютере (просто проверить, что работает)

```bash
pip install --break-system-packages -r requirements.txt  # зависимостей нет, urllib встроен
python watch.py
```

Первый запуск только сохранит текущее состояние (алертов не будет — не с чем
сравнивать). Второй и последующие запуски уже покажут изменения.

Чтобы это работало "само" на твоём компьютере — добавь в Task
Scheduler (Windows) или cron (Mac/Linux) запуск `python watch.py` каждые
15 минут. Минус: работает только пока компьютер включён.

### Вариант Б: бесплатно и круглосуточно через GitHub Actions (рекомендую)

1. Создай **приватный** репозиторий на GitHub, залей туда все файлы этой
   папки (включая `.github/workflows/watch.yml`).
2. В настройках репозитория: **Settings → Secrets and variables → Actions**
   → добавь два секрета:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. Готово — GitHub будет сам запускать проверку каждые 15 минут, бесплатно
   (публичные и приватные репозитории с малым использованием попадают в
   бесплатный лимит GitHub Actions), даже если твой компьютер выключен.
4. Адреса кошельков остаются только у тебя в приватном репозитории — никто
   кроме тебя их не видит.

## Что делает скрипт

- Спот-баланс: если у кошелька изменился баланс HYPE/WLD/NEAR/ONDO/TAO/LIT
  больше чем на `threshold_usd` — пришлёт 🟢 приход / 🔴 уход.
- Перп-позиции: если открылась/закрылась/изменилась позиция на бирже
  Hyperliquid значительнее порога — пришлёт направление (лонг/шорт) и объём.
- Цены берутся живыми с того же бесплатного API (`allMids`), обновлять
  вручную не нужно.

## Ограничения (честно)

- Отслеживает только активность **на Hyperliquid** (спот + перпы). Если кит
  переведёт токены на другую сеть/биржу через мост — это увидит другой
  инструмент (HyperEVMScan для EVM-слоя), сюда можно добавить отдельно позже.
- GitHub Actions cron не гарантирует ровно 15 минут — иногда задержка
  в несколько минут при высокой нагрузке на бесплатном тире, это нормально.
